# Unfazed — Dating Presence Trainer

A mobile-first PWA for calm, playful, decisive dating communication: a daily 5-minute workout, location playbooks (gym, grocery & shops, street, cafés, bars), a Try-Hard vs. High-Value library, a scenario simulator, an out-loud opener & banter arena with live transcript, and a personal vault.

Plain HTML/CSS/JS — no build step. All progress is stored in `localStorage` on your device.

Open on iPhone in Safari → Share → **Add to Home Screen**.
